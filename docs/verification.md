# Verification record

On the development macOS arm64 host with Apple Clang 21 and OpenSSL 3.6.4, release, ASan/UBSan and TSan builds each passed all 15 CTest cases, including mutual TLS, core, recovery and injected faults, protocol, bounded queues, network pressure and concurrency, sharding, differential comparison, and native and Python ITCH. The expanded independent model run passed 100 fixed seeds of 1,000 commands each. These checks cover tested cases; they are not proofs of correctness or power-loss durability. Re-run after changes.

Coverage-guided libFuzzer ran locally with ASan/UBSan: 100,000 inputs for each target using seeded corpora, including a synthetic ITCH lifecycle. The final runs reported 664 coverage counters / 1,846 features for protocol and 1,586 counters / 5,169 features for ITCH; these are libFuzzer run-specific signals, not code coverage percentages. Apple Command Line Tools lacked the fuzzer archive, so the runtime was built from official LLVM compiler-rt 21.1.8 source. `scripts/fuzz-local.sh` downloads the pinned release archive, checks SHA-256 `dd54ae21aee1780fac59445b51ebff601ad016b31ac3a7de3b21126fd3ccb229`, builds the archive locally, instruments both harnesses and runs them. Set `ASTERBOOK_FUZZ_RUNS` to adjust the budget. The runtime and generated corpus remain under ignored `build/`. CI also configures Linux Clang fuzz targets; configuration is not evidence of a remote CI run.

A small exploratory scheduled-arrival measurement is saved at [local-smoke.json](../bench/results/local-smoke.json), with dirty pre-commit source, build and host metadata. It predates source-tree digest capture and is not a capacity claim. New open-loop runs record a source-tree SHA-256 alongside environment metadata; see [benchmarking](benchmarking.md).

The OpenSSL 3.5.8 local bootstrap was downloaded, checksum-verified, built, and used in a separate static-link build on this host.
