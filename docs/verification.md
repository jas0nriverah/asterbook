# Verification record

On the development macOS arm64 host with Apple Clang 21 and Python 3.14, the release build and its CTest suite exercised matching, recovery, injected process faults, protocol, bounded queue, network framing and pressure, concurrent clients, sharding, seeded differential comparison and the offline ITCH subset. A separate expanded differential invocation compared full event lists and state after each command for 100 fixed seeds of 1,000 commands. ASan/UBSan and TSan use separate builds. These checks cover tested cases and are not proofs of correctness or power-loss durability.

The Apple Command Line Tools installation on this host lacks `libclang_rt.fuzzer_osx.a`, so the optional libFuzzer target could not link here. The CI workflow builds and runs it on Linux with Clang; this workflow is configuration, not a claim that a remote CI run has passed. A small exploratory scheduled-arrival measurement is saved at [local-smoke.json](../bench/results/local-smoke.json), with dirty pre-commit source, build and host metadata. It is not a capacity claim.

After the final recovery and parser changes, the ASan/UBSan and TSan configurations each passed all 12 CTest cases. A fixed-seed portable parser smoke test also completed 1,000,000 random and mutated inputs under ASan/UBSan. This is a crash/undefined-behavior smoke check, not coverage-guided fuzzing or a semantic oracle. Reproduce with `build/asan/parser_smoke 1000000`. The sample predates source-tree digest capture and therefore has no exact digest; new open-loop runs record a SHA-256 of source/configuration files, excluding build outputs, runtime data, benchmark results and local environments.
